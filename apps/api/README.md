# BBR API

## Use recomended node version  
```sh
nvm install
nvm use
```

## Use recomended pnpm version
```sh
npm i -g pnpm@8.7.5
```

## Installation Guide

To install all the dependencies of the project, run the following command:

```sh
cd apps/api
pnpm install
```

## Usage

To start the application,run the following command:
```sh
cd apps/api
pnpm copy-env
pnpm dev
```
